## Standards and registry material

The `data/sources.json`, special-address registries, cloud profiles, lesson references, and article links record sources and review dates. IANA registries, RFC Editor publications, official cloud documentation, IEEE OUI material, IETF protocol documents, OWASP guidance, and FIRST CVSS documentation are referenced for factual interoperability information. The explanatory prose and curated practice questions are original to this project.

The included OUI file is a small, labeled reference subset, not the complete IEEE registry. MAC randomization, virtualization, locally administered addresses, and unlisted prefixes limit vendor inference. Source terms still apply to any replacement or expanded dataset you import.

Port registrations and protocol numbers do not prove what a service actually runs on a network. IANA special-use flags describe registry properties and do not guarantee global route reachability. Cloud profiles are versioned examples with documented exceptions and should be reviewed before production allocation.
