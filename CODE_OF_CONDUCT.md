# Code of conduct

This project welcomes questions, corrections, thoughtful disagreement, and contributions from people with different levels of experience.

Treat people with respect. Discuss evidence and code without personal attacks. Do not harass, threaten, discriminate, publish private information, or pressure someone to disclose personal details. Give useful feedback, credit others’ work, and respect a contributor’s stated boundaries.

Maintainers may remove inappropriate material, limit participation, or decline a contribution that violates these expectations. Responses should be proportionate and protect affected people’s privacy.

Report a concern privately to the operator or maintainer using the installation’s contact channel. Do not post another person’s private information in a public issue. The deployment owner must publish a reachable support channel before opening a public community.
