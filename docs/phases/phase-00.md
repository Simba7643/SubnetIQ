# Phase 0 — Research and architecture

The complete 21-page research report is included as `phase-00-research.pdf`. It covers competitors, practical gaps, a consolidated feature scope, architecture, data/math/security decisions, the intended folder tree, phase sequence, and primary source references.

The initial workflow requested approval between phases. The subsequent user instruction explicitly authorized finishing all phases continuously and delivering the phase and complete source ZIPs. Implementation therefore proceeded through phases 1–11 without additional phase approval stops.

The phase documents describe the final delivered implementation. The phase-organized archive is a review/navigation aid over that final source, rather than a set of historical intermediate releases.
