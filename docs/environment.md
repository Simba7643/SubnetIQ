# Environment reference

Use `apps/api/.env` for the backend and `apps/web/.env` for Vite. The root `.env.example` is a consolidated reference. Templates intentionally contain no comments; this document explains every variable. Empty optional fields are valid in guest development mode.

## API

| Variable                    | Development default                  | Meaning and production guidance                                                                                                                                                                                                |
| --------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `NODE_ENV`                  | `development`                        | `development`, `test`, or `production`. Production applies fail-closed startup checks.                                                                                                                                         |
| `HOST`                      | `0.0.0.0`                            | HTTP bind address.                                                                                                                                                                                                             |
| `PORT`                      | `3001`                               | API listening port; a host may inject its own value.                                                                                                                                                                           |
| `WEB_ORIGINS`               | `http://localhost:5173`              | Comma-separated exact HTTP(S) origins. No paths, credentials, or wildcard. Production requires HTTPS.                                                                                                                          |
| `TRUST_PROXY_HOPS`          | `0`                                  | Explicit trusted proxy hop count. Use the documented host topology; Render commonly places one trusted edge in front of the service. Do not blindly trust arbitrary forwarded headers.                                         |
| `SUPABASE_URL`              | empty                                | Supabase API origin. Set together with the anonymous key. Production requires HTTPS.                                                                                                                                           |
| `SUPABASE_ANON_KEY`         | empty                                | Public project API key used with each verified user’s bearer token so RLS remains active.                                                                                                                                      |
| `SUPABASE_SERVICE_ROLE_KEY` | empty                                | Server-only key for bounded service functions, trusted quiz grading, guest feedback, account cleanup, atomic quotas, and shared snapshot resolution. Never expose through `VITE_*`.                                            |
| `AI_PROVIDER`               | `mock`                               | `mock`, `openai`, `anthropic`, or `gemini`. Only OpenAI has an implemented live adapter in this release. Other unimplemented selections remain explicit and fall back to labeled demonstrations.                               |
| `OPENAI_API_KEY`            | empty                                | Server-only live provider key.                                                                                                                                                                                                 |
| `OPENAI_MODEL`              | `gpt-4.1-mini`                       | Operator-selected Responses API model. Ensure the configured account can access it.                                                                                                                                            |
| `ANTHROPIC_API_KEY`         | empty                                | Reserved adapter configuration; no live Anthropic implementation is claimed.                                                                                                                                                   |
| `GEMINI_API_KEY`            | empty                                | Reserved adapter configuration; no live Gemini implementation is claimed.                                                                                                                                                      |
| `AI_MAX_OUTPUT_TOKENS`      | `1200`                               | Output cap, 128–4096 tokens.                                                                                                                                                                                                   |
| `AI_DAILY_LIMIT`            | `30`                                 | Per-subject assistant request allowance per 86,400-second bucket, 1–1000. The service also has general route limits.                                                                                                           |
| `AI_TIMEOUT_MS`             | `60000`                              | Streaming request timeout, 1000–180000 ms.                                                                                                                                                                                     |
| `LOOKUP_TIMEOUT_MS`         | `7000`                               | Lookup timeout, 1000–15000 ms.                                                                                                                                                                                                 |
| `LOOKUP_MAX_CONCURRENT`     | `8`                                  | Lookup concurrency bound, 1–32.                                                                                                                                                                                                |
| `WHOIS_FALLBACK_ENABLED`    | `false`                              | Explicitly enable the limited WHOIS fallback. RDAP remains the primary IP registration path.                                                                                                                                   |
| `QUOTA_STORE`               | `memory` in the development template | `memory` or `postgres`. Production requires `postgres`, applied migrations, and service credentials. In-process development quotas do not coordinate multiple servers.                                                         |
| `RATE_LIMIT_SECRET`         | empty                                | A random per-process development value is generated when omitted. Production requires a stable secret of at least 32 characters. Generate one with `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`. |
| `LOG_LEVEL`                 | `info`                               | `silent`, `error`, or `info`. Logs use operational fields rather than request bodies and secrets.                                                                                                                              |

## Frontend build values

Vite substitutes these values at build time. Rebuild the frontend after changing them. All `VITE_*` values are public; they cannot hold provider or service-role secrets.

| Variable                    | Default                 | Meaning                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VITE_API_URL`              | empty                   | Empty means same-origin `/api`, proxied by Vite locally or Nginx in Docker. For separate Vercel/Render hosts, use the API HTTPS origin without `/api` or a trailing slash.                                                                                                                                                                                              |
| `VITE_SUPABASE_URL`         | empty                   | Public Supabase URL. Set together with the anonymous key.                                                                                                                                                                                                                                                                                                               |
| `VITE_SUPABASE_ANON_KEY`    | empty                   | Public anonymous project key. Every private operation still requires the user’s verified session and database policy.                                                                                                                                                                                                                                                   |
| `VITE_SITE_URL`             | `http://localhost:5173` | Canonical public origin used for metadata and sitemap generation. Set the real HTTPS frontend URL before building for production.                                                                                                                                                                                                                                       |
| `VITE_APP_NAME`             | `SubnetIQ`              | Branding configuration entry retained for renaming. The supplied visual and legal brand text also needs review when rebranding; it is not a universal text replacement.                                                                                                                                                                                                 |
| `VITE_ANALYTICS_PROVIDER`   | `none`                  | `none` disables analytics. `plausible` enables the optional integration only with the remaining analytics values and user consent.                                                                                                                                                                                                                                      |
| `VITE_ANALYTICS_DOMAIN`     | empty                   | Analytics site/domain identifier.                                                                                                                                                                                                                                                                                                                                       |
| `VITE_ANALYTICS_SCRIPT_URL` | empty                   | Current Plausible site-specific HTTPS script ending in `pa-<site-key>.js`, copied from its installation settings. The application rejects legacy `script.js` and `script.manual.js` URLs, initializes `autoCapturePageviews: false`, and filters every event against consent and public routes. Query strings, fragments, referrers, and custom properties are omitted. |

## Local OAuth and email

The application completes callbacks on `/auth`, including `returnTo` and `mode=reset` query parameters. Local Supabase configuration allows the relevant `/auth**` paths on ports 5173 and 8080. In a hosted project, use the exact production origin and an appropriate `/auth**` allow pattern in Supabase Auth settings. Configure the upstream OAuth application’s Supabase callback URL as shown by Supabase.

Local email appears in the Supabase development mailbox. Hosted email delivery, OAuth application credentials, and account recovery settings require operator configuration and are not simulated by the application.

## Production checklist

Set `NODE_ENV=production`, `QUOTA_STORE=postgres`, a stable `RATE_LIMIT_SECRET`, all required Supabase values, HTTPS `WEB_ORIGINS`, and the actual proxy hop count. Apply migrations before enabling traffic. Keep API-only secrets in the host’s secret store. Build web assets with public values and the correct canonical URL. Verify `/api/ready`, sign-in, user separation, private storage, project shares, and a small live AI request after configuration.
