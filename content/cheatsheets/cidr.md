# IPv4 CIDR and mask reference

Total counts are mathematical. Conventional LAN capacity applies to /0–/30; /31 uses an explicit RFC 3021 point-to-point policy, and /32 is a single address. A mathematical capacity does not mean every address in a broad block is available for assignment. Cloud providers and designs can reserve additional positions.
