# Powers of two and octet weights

An octet uses weights 128, 64, 32, 16, 8, 4, 2, 1. An unsigned octet has 256 patterns numbered 0–255. One hexadecimal digit represents four bits.

Worked example: 214 = 128 + 64 + 16 + 4 + 2 = binary 11010110.

Binary AND of 11010110 and 11100000 gives 11000000, or decimal 192.

A byte is eight bits. Decimal MB uses 1,000,000 bytes; MiB uses 1,048,576 bytes. State units before calculating transfer time.
